# Privacy Policy — Clean Code Standards

_Last updated: 26 November 2026_

Clean Code Standards is a set of written instructions (a skill) for Claude. It contains no code, scripts, connectors or MCP servers.

- **No data collection:** the plugin does not collect, store, or transmit any personal data or code.
- **No third parties:** the plugin does not send data to any external service.
- **No retention:** the plugin keeps no data of any kind.

Anything you share while using Claude is handled by Anthropic under its own privacy policy: https://www.anthropic.com/legal/privacy

Questions: open an issue at https://github.com/prasoon-88/clean-code-standards/issues
